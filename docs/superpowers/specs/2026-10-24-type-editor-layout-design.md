## 可观察设计

1. 类型选择为独立字段：标签在上，完整宽度的深色 select 在下。仅沉积类别显示的
   沉积模式字段使用相同结构，位于类型字段之后；配置按钮独立一行。
2. 延续既有检查器视觉：深色底、浅色字、细边框和适度间距；控件可点击高度至少
   30 px，键盘 focus-visible 使用清晰轮廓，禁用状态与现有控件一致。
3. 旧类型说明、模板缺失警告和候选配置说明各占独立文本块，长文本自动换行。
   未选新类型不误报模板缺失；真正缺模板继续警告并禁用，不能借样式改变门禁。
4. 内联候选表单继续在原位置展开。仅在此编辑区内补齐候选标题、说明、自定义名称、
   数字／文本／选择控件与操作栏的深色排版；复用既有字段样式，不建立第二套表单。
   checkbox 和 range 保持各自交互尺寸，不套用普通输入框的整行外观。
5. 候选的取消／确认按钮允许换行，标签和长文案可读。默认 320 px 与最窄 260 px
   右栏均不造成该编辑区的横向溢出；内容增多使用既有面板纵向滚动，不裁掉字段。
   中英文、浏览器 200% 缩放下仍能操作，不增加新的固定宽高。
6. 继续使用原生 label、select、button 与表单，保持 label/control 关联、键盘顺序、
   确认按钮类型及现有可访问名称。不通过伪元素代替真实标签，不用自绘菜单。
